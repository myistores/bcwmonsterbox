# BCWMonsterBox.com — GitHub Pages site

Static SEO-focused independent product guide for BCW Monster Storage Box SKU 1-BX-MON.

## Before launch
1. Replace `https://collectiblesupply.com/` in `index.html` (id `buy-link`) with the exact CollectibleSupply.com SKU 1-BX-MON product URL. Add campaign parameters if desired, e.g. `?utm_source=bcwmonsterbox&utm_medium=referral&utm_campaign=monster_box` (use `&` instead of `?` if URL already contains a query string).
2. Verify dimensions, claims, images usage rights and current retailer identity. Manufacturer material may require permission for redistribution.
3. Upload all files to the ROOT of a GitHub repository; Settings → Pages → Deploy from branch → main / root.
4. Configure domain DNS and HTTPS according to https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site . Verify domain ownership.
5. Set up Google Search Console domain property, submit sitemap.xml, connect GA4 if desired, and test outbound clicks.
6. If using a public repository, never include passwords, API keys or private business data.

No price/availability claims or fabricated reviews are included. Schema intentionally omits Offer pricing until a real, maintained price and checkout URL are available.
